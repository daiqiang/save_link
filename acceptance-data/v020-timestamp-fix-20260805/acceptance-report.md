提交 `a8fb0fe fix: 统一跨设备快照时间格式` 回归通过，`BUG-01` 可以关闭：

- 旧 `YYYY-MM-DD HH:MM` 快照时间可无损迁移为 UTC RFC 3339，重复启动幂等。
- 本机、云端目录和设备 B 时间线统一显示本地 `YYYY-MM-DD HH:MM`。
- 下载快照与当前存档、本机快照与当前存档两段无变化去重均通过。
- 31 条混合来源快照按真实时间淘汰最老的云端接收快照，最终保留 30 条。
- 被淘汰快照的百度 `.ok/.zip`、本地快照和本轮云同步记录均删除。
- 测试游戏远端目录和 profile A/B 隔离 Token 已清理。

未发现该修复引入的阻塞问题。`PKG-01` 已确认是本机搜狗压缩软件造成的环境现象，不属于 SaveLink 缺陷；开发包版本仍为 `0.1.0`，C-02/C-03/C-05/C-06 故障注入暂缓项保持不变。
