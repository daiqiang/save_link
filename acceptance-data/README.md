## 目录用途

本目录保存 SaveLink 人工验收使用的假游戏存档和历史验收现场，用来验证添加游戏、扫描目录、创建快照、编辑路径、恢复、中文路径和损坏快照保护等功能。

这些文件不是用户的真实游戏存档，也不是 SaveLink 的运行数据。正式应用不会自动读取本目录，绿色版和安装包也不会包含本目录。

## 当前内容

| 路径 | 用途 |
| --- | --- |
| `saveA/` | 普通多文件假存档，用于创建快照、无变化检测、文件变化和替换式恢复测试 |
| `saveC/` | 包含中文文件名和中文子目录，用于验证中文路径与嵌套目录 |
| `edit-path-target/` | 用于验证编辑游戏后切换存档路径 |
| `smoke-20260630/` | 2026-06-30 基线冒烟测试留下的简单存档现场 |
| `appdata-backup-20260630-211419/` | 早期验收留下的 SQLite 与快照仓库现场，其中包含故意损坏的快照，可用于旧数据兼容和损坏快照保护复查 |

手动测试计划还会使用空目录 `saveB_empty/`。Git 不会保存空目录，因此新工作区中可能看不到它；测试空存档时按测试计划手动创建即可。

## 使用注意

- 人工测试会修改、增加或删除假存档中的文件。需要可重复结果时，先复制一份再操作。
- 第一次验收不要把 SaveLink 指向唯一的真实游戏存档，应优先使用本目录或其他临时目录。
- `appdata-backup-20260630-211419/` 是历史测试现场，不是当前用户数据备份。不要直接覆盖到正式 `%APPDATA%\com.daiq.savelink`。
- 新增一次性验收数据时优先使用带日期的子目录；只有可重复使用的测试夹具才建议提交 Git。
- 清理本目录前先检查 `savelink-app/手动测试计划.md` 和其他验收文档中的引用，不要直接删除整个目录。
