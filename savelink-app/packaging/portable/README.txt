一、开始使用

1. 请先完整解压压缩包，不要直接在 zip 中运行程序。
2. 双击 SaveLink.exe 启动。
3. 添加游戏并选择该游戏的真实存档目录。
4. 点击“创建快照”保存当前存档状态。
5. 需要回档时选择目标快照并点击“恢复”。当前版本不会自动备份恢复前的存档；如需保留当前进度，请先手动点击“创建快照”。

二、百度网盘

1. 当前版本需要用户手动点击快照上的“上传”按钮，SaveLink 不会自动上传全部快照。
2. 首次上传时，默认浏览器会打开百度授权页面。
3. 普通百度网盘账号可以使用，不需要注册百度开发者，也不需要预先安装或启动百度网盘客户端。
4. 在另一台电脑上，打开右上角“云端存档”，授权同一个百度账号后即可发现和下载云端快照。
5. 下载只会把快照放入本机 SaveLink 仓库。绑定本机存档目录并手动点击“恢复”后，才会写入真实游戏存档目录。

三、数据位置

SaveLink 的数据库、快照仓库和百度授权信息不保存在本程序文件夹，而是保存在：

%APPDATA%\com.daiq.savelink

因此，删除或替换本程序文件夹不会自动删除已有快照。

四、升级

1. 关闭正在运行的 SaveLink。
2. 解压新版本压缩包。
3. 运行新版本中的 SaveLink.exe。

已有游戏、快照和授权信息会继续从 AppData 数据目录中读取，不需要手工迁移。

五、卸载

只删除解压后的 SaveLink 程序文件夹即可停止使用。

如需彻底删除本机数据库、快照和百度授权信息，可以另外删除：

%APPDATA%\com.daiq.savelink

删除该数据目录后，本机尚未上传到云端的快照将无法恢复，请谨慎操作。

六、运行环境

- Windows 10/11 64 位系统。
- 需要 Microsoft Edge WebView2 Runtime；大多数较新的 Windows 系统已经自带。
