# SaveLink v0.5.2 加载器真实程序识别方案

更新日期：2026-09-27

## 1. 背景

部分游戏并不直接通过真实游戏 EXE 启动，而是先运行第三方加载器。例如本次验证的《王国保卫战6》使用：

```text
steamclient_loader.exe
```

同目录的 `ColdClientLoader.ini` 指向实际游戏程序：

```ini
[SteamClient]
Exe=Kingdom Rush Genesis.exe
ExeRunDir=.
AppId=2115380
```

SaveLink 当前使用用户填写的游戏名称和直接启动程序名称参与候选目录评分。本例中直接启动程序是 `steamclient_loader.exe`，用户填写的中文名称也无法匹配真实存档目录：

```text
C:\Users\daiqiang\AppData\Roaming\kingdom_rush_genesis
```

该目录在一次正常游玩中出现 297 次有效变化，并同时具有多个文件变化、新建文件和修改已有文件等强动态信号，评分达到 37 分，但因缺少游戏身份关联信号仍被判定为低可信。

## 2. v0.5.2 目标

在已知加载器配置能够明确指出真实游戏程序时，解析真实 EXE，并使用真实 EXE 的身份信息参与存档候选评分。

本阶段只实现确定性较高的加载器配置解析，不实现通用子进程追踪。

## 3. 识别流程

### 3.1 判断是否为受支持的加载器

添加游戏或开始存档探测前，检查启动程序所在目录是否存在受支持的配置文件。

v0.5.2 第一阶段支持：

- `ColdClientLoader.ini`
- 读取 `[SteamClient]` 下的 `Exe` 字段

不能仅凭启动文件名为 `steamclient_loader.exe` 就认定其真实程序或提高候选评分。

### 3.2 校验真实 EXE 路径

配置文件中的 `Exe` 必须满足：

- 是相对于当前游戏安装目录的路径；
- 规范化后仍位于当前游戏安装目录内，不能通过 `..` 逃逸；
- 目标文件真实存在；
- 目标扩展名为 `.exe`；
- 解析或校验失败时保持现有逻辑，不影响启动和存档探测。

### 3.3 提取真实游戏身份

从经过校验的真实 EXE 提取：

- EXE 文件名和文件名 stem；
- `ProductName`；
- `FileDescription`；
- `OriginalFilename`；
- `CompanyName` 只用于展示或辅助诊断，不作为主要路径匹配依据。

所有可用于匹配的身份字符串统一执行大小写、空格、下划线、连字符和非字母数字字符归一化。例如：

```text
Kingdom Rush Genesis.exe -> kingdomrushgenesis
kingdom_rush_genesis     -> kingdomrushgenesis
```

### 3.4 参与候选目录评分

将真实 EXE 身份作为额外身份键传入存档活动分析上下文。候选路径与任一可靠身份键匹配时，获得“路径与实际游戏程序相关”信号。

本例现有动态活动评分为 37 分；真实 EXE 身份匹配预计再增加 12 分，总分约 49 分，同时满足高可信候选所要求的游戏领域关联信号。

评分提升必须同时依赖真实文件活动。加载器配置或 EXE 名称本身不能在没有存档活动的情况下生成高可信候选。

## 4. AppID 处理规则

加载器配置中的 `AppId` 只作为诊断信息和弱提示，不直接提供高可信加分。

原因包括：

- 第三方加载器中的 AppID 可能错误、复用或被修改；
- 学习版游戏的 AppID 不一定能从 Steam 官方接口获得有效信息；
- AppID 与真实存档位置未必存在直接路径关系。

若未来使用 AppID 参与识别，必须先经过可靠来源验证，并与真实 EXE 身份或运行时证据共同使用。

## 5. 失败与兼容策略

- 没有配置文件：继续使用当前评分逻辑；
- 配置格式错误：记录诊断信息，不阻塞游戏启动；
- `Exe` 不存在或路径越界：忽略该配置，不提高候选评分；
- EXE 版本信息缺失：仍可使用经过校验的文件名 stem；
- 用户填写的中文名称与英文程序名不同：由真实 EXE 身份补充匹配；
- 不因扩展名为 `.lua`、文件名包含 `slot` 或目录变化次数较多而单独升级为高可信。

## 6. 测试计划

### 6.1 单元测试

- 正确解析 `ColdClientLoader.ini` 的 `Exe`；
- 支持带空格、相对路径和大小写差异；
- 拒绝通过 `..` 逃逸安装目录；
- 拒绝不存在的 EXE 和非 EXE 文件；
- 身份归一化后 `Kingdom Rush Genesis` 能匹配 `kingdom_rush_genesis`；
- 配置解析失败时保持旧评分结果。

### 6.2 集成验证

- 通过 `steamclient_loader.exe` 启动《王国保卫战6》；
- 正常游玩、保存并退出；
- `AppData\Roaming\kingdom_rush_genesis` 成为高可信候选；
- 浏览器、百度网盘和 Steam 缓存目录仍保持低可信；
- 不依赖不可靠的 `AppId=2115380` 完成判断。

## 7. 后续待办：通用运行时兜底

本功能不在 v0.5.2 实现，后续版本单独设计：

- SaveLink 启动加载器后跟踪其创建的子进程和后代进程；
- 从位于游戏安装目录内的真实运行进程获取 EXE 路径和版本身份；
- 在没有配置文件、配置格式未知或加载器文件名变化时补充游戏身份；
- 处理加载器快速退出、多个子进程、辅助程序和反作弊进程的筛选；
- 只有可靠定位到真实游戏进程后才将身份用于高可信评分。

该待办用于扩展其他加载器，不应通过硬编码更多加载器文件名代替进程级识别。

## 8. 完成标准

- 不改变普通直接启动游戏的现有评分结果；
- 经过安全校验的真实 EXE 身份可以参与候选目录匹配；
- 本例真实存档目录能够稳定进入高可信；
- 错误或恶意配置不能越过游戏安装目录读取任意 EXE；
- 相关单元测试、核心测试和前端构建通过。
