## 推荐入口

第一次接手项目时，建议按以下顺序阅读：

1. `PROGRESS.md`：当前进度、v0.5.1 发布收口和暂停中的 v0.6.0 规划。
2. `HANDOFF-codex.md`：开发约定、验证命令、风险红线和交接说明。
3. `SaveLink-v0.6.0云任务调度与冲突治理方案.md`：当前主线的任务类型、资源键、队列、状态机、删除语义、未读提醒和实施顺序。
4. `SaveLink-v0.2.0自动备份方案.md`：自动检查、自动上传、历史上限和待定产品规则。
5. `SaveLink-v0.2.0自动备份专项验收用例.md`：v0.2.0 开发包的本地验收步骤、通过门槛和执行记录。
6. `SaveLink当前功能完成情况.md`：面向总规划会话的当前状态摘要。
7. `SaveLink技术架构.md`：技术栈、模块、数据模型和关键实现。
8. `SaveLink恢复与存储测试规格.md`：存档安全与恢复链路的验收基准。
9. `SaveLink-Steam自动发现与多存档目录验收报告-20260810.md`：v0.3.0 Steam 发现与多目录实机验收证据。
10. `SaveLink-v0.4.0-DeSmuME模拟器支持方案.md`：v0.4.0 DeSmuME 范围、ROM 身份、精确 `.dsv` 保护、云端边界和验收标准。
11. `SaveLink游戏启动与存档动态发现方案.md`：未知/学习版游戏先登记 EXE、再启动监测、确认存档候选和接入自动备份的设计基线；阶段 1 至 5 已完成并经过多个真实学习版样本验收。
12. `SaveLink游戏运行期短周期快照与退出收尾方案.md`：记录未来游戏运行中短周期去重快照、进程退出最终检查、竞品证据和实施阶段；当前尚未实现。

`PROGRESS.md` 和 `HANDOFF-codex.md` 保留英文约定名，方便 Codex、Claude Code 等开发 Agent 快速识别；其他项目文档使用中文文件名。
