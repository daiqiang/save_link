## 推荐入口

第一次接手项目时，建议按以下顺序阅读：

1. `PROGRESS.md`：当前进度、v0.2.0 主线和 v0.1.0 并行待办。
2. `HANDOFF-codex.md`：开发约定、验证命令、风险红线和交接说明。
3. `SaveLink-v0.2.0自动备份方案.md`：自动检查、自动上传、历史上限和待定产品规则。
4. `SaveLink-v0.2.0自动备份专项验收用例.md`：v0.2.0 开发包的本地验收步骤、通过门槛和执行记录。
5. `SaveLink当前功能完成情况.md`：面向总规划会话的当前状态摘要。
6. `SaveLink技术架构.md`：技术栈、模块、数据模型和关键实现。
7. `SaveLink恢复与存储测试规格.md`：存档安全与恢复链路的验收基准。

`PROGRESS.md` 和 `HANDOFF-codex.md` 保留英文约定名，方便 Codex、Claude Code 等开发 Agent 快速识别；其他项目文档使用中文文件名。
